# Richman iOS (richman-ios)

A modern iOS take on the classic Taiwanese board game series **大富翁 1/2/3** ("Richman" / "Rich Dragon") — a top-down, tile-board Monopoly-style game.

The twist: **pick any real city** (e.g. New York, Taipei, Tokyo) and the board is generated from that city's actual streets, train/metro stations, and landmarks, laid out to echo the city's real geography.

## Status

Early scaffolding. See [`Docs/ARCHITECTURE.md`](Docs/ARCHITECTURE.md) for the module map and [`Docs/CONTRIBUTING.md`](Docs/CONTRIBUTING.md) for how to build, test, and contribute (including guidance for other AI coding agents working in this repo).

## Project structure

- `App/` — thin SwiftUI app shell (Xcode project generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`).
- `Packages/RichmanCore` — the game engine (board, players, turns, cards, economy). No UI, no networking.
- `Packages/RichmanCityData` — turns a city name into a real-world board layout, using OpenStreetMap (Nominatim + Overpass).
- `Packages/RichmanAssetsKit` — the seam where real art/sound/video assets get plugged in. Ships with placeholder visuals so the game is playable today.
- `Packages/RichmanPersistence` — save/load game state and cached city data.
- `Packages/RichmanGameUI` — SwiftUI views for the board, HUD, dice, and dialogs.

## Building

Requires Xcode (full install, not just Command Line Tools) and [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
brew install xcodegen
xcodegen generate
open RichmanApp.xcodeproj
```

Each package under `Packages/` is a standalone Swift package and can be built/tested independently without opening Xcode:

```bash
cd Packages/RichmanCore && swift test
```
